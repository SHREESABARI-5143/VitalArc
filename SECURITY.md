# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of **VitalArc** seriously. If you believe you have found a security vulnerability, please do not disclose it publicly on GitHub issues.

### Reporting Process:
1. Privately email details of the vulnerability to the project maintainers or create a private security advisory on GitHub.
2. Provide a clear description of the vulnerability, reproduction steps, and potential clinical or operational impact.
3. We will acknowledge receipt of your vulnerability report within 48 hours and provide a timeline for remediation.
